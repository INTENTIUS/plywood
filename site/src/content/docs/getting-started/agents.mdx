## The agent's steps

1. Read [llms.txt](/plywood/llms.txt) and this page.
2. Run `npm i -D @intentius/plywood` and `npx plywood init`.
3. Ask you which stacks wait for an approval, and set `gate` in `plywood.yml` to match.
4. Commit the result on a branch and open a pull request.

## The agent's limits

Updates, approvals and merges belong to a person. The prompt ends with that rule word for word, and the agent stops at the pull request.

The pull request's own preview note then shows the agent's work, like any other change.
