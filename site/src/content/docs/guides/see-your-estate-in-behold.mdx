behold, chant's console, reads the workspace ledger along with the snapshots under `refs/chant/snapshots`. Each stack shows its resources and its last update, with any drift beside them.

```sh
npx chant workspace graph
```

Run `plywood view` in the repository to open behold on it, at the release this plywood pins, until you press Ctrl-C.

```sh
npx plywood view
```
