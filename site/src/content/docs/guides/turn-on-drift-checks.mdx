```yaml
drift:
  schedule: "0 6 * * *"
```

The drift job runs chant's [drift detection](https://intentius.io/chant/concepts/drift-detection/) on each stack. On stock Pulumi it runs `pulumi refresh --preview-only`. Each drifted stack gets one issue that names each URN and attribute, and the issue closes once the stack matches.
