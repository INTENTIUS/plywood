<WithPlunge claim="per-resource-progress" feature="per-resource timings of each provider call and record write during up" />

plunge times each provider call and each record write during `up`. In the `up` job's trace each resource gets a child span under its stack with its provider and record time. The stack's span carries the totals and the slowest call. A failed update keeps the timings of the resources it reached.

The wave's run record on the ledger keeps the same spans and totals. The package's dashboard preset (`presets/dashboards/plywood.json`) has a table of plunge updates per stack and one per resource.
