| Stage | Runs on | Writes |
|---|---|---|
| `check` | every push | the check report |
| `preview` | every pull request push and `/plywood preview` | the note, the status, the change set |
| `up` | merge, or `/plywood up` | the update, its ledger row and the snapshot |
| `drift` | the schedule | one issue per drifted stack |

<Tabs syncKey="engine">
<TabItem label="Pulumi">
| Stage | Command |
|---|---|
| `check` | `pulumi install`, `pulumi config` validation, `pulumi about` |
| `preview` | `pulumi preview --json` |
| `up` | `pulumi preview --json` again, compared with the approved shape, then `pulumi up --yes --json` |
| `drift` | `pulumi refresh --preview-only --json` |
</TabItem>
<TabItem label="plunge">
| Stage | Command |
|---|---|
| `check` | the same as Pulumi |
| `preview` | `plunge preview --json --save-plan <file>` |
| `up` | `plunge up --plan <file> --yes --json`, which refuses a record that moved |
| `drift` | `plunge drift --resource <urn> --stream` |

With plunge, the pipeline also gets a saved plan stamped with each record's version. Its status is on [plunge's claims page](https://intentius.io/plunge/claims/).
</TabItem>
</Tabs>
